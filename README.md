# 🏆 対戦表メーカー

集まりや遊びの場で、トーナメント表・リーグ表をその場で作り、タップだけで勝敗を記録できるツールです。
**依存ライブラリなし・ビルド不要**の静的サイトなので、`index.html` をブラウザで開くだけで動きます。

要件は [docs/requirements.md](docs/requirements.md)、実装との対応状況は [docs/gap-analysis.md](docs/gap-analysis.md) にあります。

## できること

| | |
|---|---|
| **2つの形式** | トーナメント（勝ち抜き）とリーグ（総当たり）を切り替えて使えます |
| **人数は自由** | 2名以上なら何名でもOK（動作保証は32名まで）。トーナメントでは**不戦勝（シード）の人数を選べます** |
| **勝敗の記録** | トーナメントは名前をタップ、リーグは星取表のマスをタップ。もう一度タップで取り消し |
| **次の試合が分かる** | まだ実施できていない試合を強調表示します |
| **勝ち負けが一目でわかる** | 勝者は緑＋✔、敗者はグレー＋取り消し線。優勝カード・表彰台・戦績表（勝/敗/敗退ラウンド）も自動生成 |
| **3位決定戦** | ON にすると準決勝の敗者同士の試合が追加されます（準決勝が2試合そろう形のときのみ） |
| **スコア記録** | ON にすると各試合に得点を入力できます。リーグの順位（得失点差）にも使われます |
| **引き分け** | リーグでのみ記録できます（勝3・分1・敗0） |
| **組み合わせ抽選** | 🎲ボタンでシャッフル。参加者リストの並び順がそのまま配置になります（一番下の人が不戦勝の候補） |
| **保存・共有** | 自動保存（localStorage）／**閲覧専用**の共有URL／JSONの保存・読込 |
| **書き出し** | 印刷（PDF保存）。PNG・SVGはトーナメントのみ |
| **オフライン対応** | 一度開けば、電波がなくても作成・記録・リロードができます |

## 使い方

1. `public/index.html` をブラウザで開く
2. 左パネルで参加者を入力（1名ずつ、または「まとめて入力」に改行区切りで貼り付け）
3. 大会名を入力
4. 「形式」でトーナメントかリーグを選ぶ
5. 試合が終わるたびに、勝った側の名前（リーグは星取表のマス）をタップ
6. 「🔗 共有URLをコピー」で全員に見せる、「🖨 印刷 / PDF」で配布用に出力

共有URLを開いた人は**閲覧のみ**で、勝敗は記録できません。URLは発行した時点の内容を持つので、試合が進んだら送り直してください。

### 不戦勝（シード）について

各ラウンドは「上から2人ずつ」組み合わせます。1回戦で戦わない人＝**不戦勝（シード）の人数は設定パネルで選べます**。シードになるのは**リストの下にいる人**なので、シードにしたい人はリストの下へ移動させてください。

選べる人数は「参加人数と同じ偶奇」の値だけです（残りが2人ずつ組めないといけないため）。たとえば11名なら 1／3／5／7／9名 から選べます。

| 選ぶ人数 | 11名のときの形 |
|---|---|
| **1名（最少・既定）** | 1回戦5試合。全員がなるべく早く登場する |
| **5名（2の累乗の枠）** | 1回戦3試合。16人枠と同じ形になり、2回戦以降に不戦勝が出ない |
| 9名 | 1回戦1試合。ほとんどの人が2回戦から登場する |

どの人数を選んでも**総試合数は必ず「参加人数 − 1」**です。

2回戦以降は、その時点の人数が奇数になったときだけ1人が不戦勝で通過します（「2の累乗の枠」を選ぶとこれは発生しません）。1回戦の免除は「シード」、2回戦以降は「不戦勝」と表示されます。


### 公開する（Cloudflare Workers）

`public/` 以下を Cloudflare Workers の静的アセットとして配信します。サーバーサイドの処理は一切ありません。参加者名を含むすべてのデータは利用者のブラウザ内に留まります。

**手元から公開する場合**

```sh
npx wrangler deploy
```

**GitHub から自動公開する場合**

`.github/workflows/deploy.yml` を用意してあるので、既定ブランチに push すれば公開されます。事前に **Settings → Secrets and variables → Actions** で次の2つを登録してください。未登録のあいだは公開をスキップするだけで、ワークフローは失敗しません。

| 名前 | 取得元 |
|---|---|
| `CLOUDFLARE_API_TOKEN` | Cloudflare ダッシュボード → My Profile → API Tokens。テンプレート「Edit Cloudflare Workers」で作成 |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare ダッシュボードのURL、または Workers の概要ページに表示される |

公開先は `taisenhyo.<サブドメイン>.workers.dev` になります。名前は `wrangler.jsonc` の `name` で変更できます。

## ファイル構成

```
public/                      配信されるファイルはこの中だけ
  index.html                 画面の構造
  assets/style.css           見た目（レイアウト定数は :root と app.js の LAYOUT を対応させています）
  assets/app.js              トーナメント／リーグの生成・勝敗の解決・描画・入出力
  sw.js                      Service Worker（オフライン対応）
wrangler.jsonc               Cloudflare Workers の設定
docs/requirements.md         要件定義書
docs/gap-analysis.md         要件と実装の対応状況
```

`public/assets/` を書き換えたときは `public/sw.js` の `CACHE` の版数を上げてください。古いキャッシュが残り続けるのを防ぐためです。

### 仕組み（概要）

- **配置** — 各ラウンドで残っている枠を上から2つずつ組んで対戦にします。1回戦の不戦勝の人数は設定で選べ、選ばれた人（リストの下位）は縦方向に散らして配置します。2回戦以降は奇数で1つ余ったときだけ、その1つが不戦勝で通過します。総試合数は必ず `参加人数 − 1` です。
- **リーグ** — 総当たりの各対戦を `L:参加者ID:参加者ID`（IDの小さい順）で識別するため、参加者を並べ替えても記録が保たれます。順位は勝点 → 得失点差 → 総得点の順に比較し、それでも並ぶ場合は同順位とします。得失点は両者の得点が入力された試合のみを集計します。
- **勝敗** — 保存するのは「どの試合で誰が勝ったか」だけ（`results: { 試合ID: { w: 参加者ID, s: スコア } }`、引き分けは `w: "draw"`）。各試合の出場者は毎回ツリーをたどって計算するため、途中の勝敗を変更すると、その先の試合は自動的に整合の取れた状態に戻ります。不戦勝の枠は対戦ではないので勝敗を持たず、勝ち数にも数えません。
- **座標** — 1回戦を上から順に並べ、2回戦以降は「前の枠の中点」に置くだけの単純な計算です。不戦勝の枠はカードを描かず、列を横切る線だけでつなぎます。画面表示（HTML＋SVGの線）と画像書き出し（純SVG）で同じ座標計算を共用しています。

## データ形式（JSON）

```jsonc
{
  "version": 1,
  "title": "第3回 社内交流戦",
  "players": [{ "id": "p1x", "name": "チームA" }],   // この並び順がブラケットの配置
  "format": "tournament",                            // "tournament" | "league"
  "byes": "min",                                     // 1回戦の不戦勝: "min" | "full" | 人数
  "thirdPlace": true,
  "showScore": false,
  "zoom": 100,
  "results": {
    "0-0": { "w": "p1x", "s": { "p1x": 3, "p2y": 1 } }  // 試合ID: ラウンド-番号（"tp" は3位決定戦）
  }
}
```

## 動作確認

Chromium（Playwright）で以下を確認済みです。

- トーナメント2〜17名と32名すべてで、全試合が決着して優勝者が決まること
- リーグの試合数・勝点・同順位・得失点差の計算、対称セルの自動反映
- 共有URLが閲覧専用であること、閲覧側の保存データを上書きしないこと
- 320px幅でページの横スクロールが起きないこと
- オフラインでもリロードして勝敗を記録できること
- 不戦勝の人数を変えても総試合数が `人数 − 1` のままで、最後まで決着すること
- 「2の累乗の枠」を選ぶと2回戦以降に不戦勝が出ないこと
- 参加人数を減らしても不戦勝の設定が有効な値に丸められること
- 不戦勝が自動で勝ち上がること／勝者の取り消しで下流がリセットされること
- カード同士が重ならないこと
- 戦績表の順位・勝敗数・敗退ラウンド表示
- URL共有・localStorage による状態の完全復元
- SVG／PNG 書き出し
- 参加者を入れ替えた際に、存在しなくなった試合の記録が残らないこと

## ブラウザ対応

Chrome / Edge / Firefox / Safari の最新版。オフラインでも動作します（外部リソースを読み込みません）。
