# 要件と現行実装の差分

- 対象要件: [requirements.md](./requirements.md) v1.0
- 対象実装: `index.html` / `assets/style.css` / `assets/app.js`（トーナメント表メーカー）
- 作成日: 2026-08-08

現行実装はトーナメント専用のプロトタイプであり、要件の**約7割を満たしている**。不足の中心は**リーグ戦**と**閲覧専用の共有**である。
